# John Robert A. Paler Portfolio

Single-page freelance IT portfolio built with Vite, React, and CSS. The content is based on `CV-PALER-FINAL-CAPSTONE.pdf` and highlights John Robert A. Paler as a full-stack developer with UI/UX capability.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Sections

- Hero with freelance CTA
- CalorieKo featured project and architecture overlay
- Interactive skills inventory
- Dual-track experience and leadership timeline
- Trainings strip
- Contact form with real-time validation and email draft handoff
